Íconos: propios contra bibliotecas

La columna Propios es el set de este kit (kit/iconos.js): trazos en una cuadrícula de 24 con las mismas reglas, y una capa de relleno opcional para las versiones duotono y sólida. Las bibliotecas se cargan desde internet solo si pulsas el botón (jsDelivr y unpkg, versiones fijas); el juego nunca se conectaría: se vendorizarían con su licencia (Lucide ISC, Phosphor MIT, Tabler MIT).

Sin cargar las bibliotecas solo se ven los íconos propios.

Huecos de cada biblioteca: Phosphor no tiene hacha (se muestra un pino) y Tabler no tiene trigo (se muestra un brote). Son el tipo de cosas propias del juego que habría que dibujar aparte con cualquier biblioteca.
