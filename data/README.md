# Datos del juego

Esta carpeta se copia junto al ejecutable al compilar.

- `lang/`: textos del motor y de los menús, un archivo por idioma (fase 2).
- `menu_backgrounds.json`: las semillas de los mapas que se ven detrás del menú principal (fase 50); en cada arranque sale una.
- `fonts/`: tipografías con sus licencias (fase 2).
- `mods/core/`: el juego base, como mod (fase 7).
